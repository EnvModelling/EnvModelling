# X11 graphical applications

EnvModelling includes X11 support for Linux graphical applications used
by some modelling workflows, such as `ncview`.

X11 is **optional**. Many plots and animations are written to files in
`~/work`; these can be opened directly from the host computer through
the `student_work` directory.

## macOS

Install **XQuartz** from its official site:

https://www.xquartz.org/

After installation, log out of macOS and back in if required by the
XQuartz installer.

Start XQuartz, then connect to EnvModelling with X11 forwarding:

``` bash
ssh -X -p 2022 student@localhost
```

Password:

``` text
envmodelling
```

A simple test is:

``` bash
xeyes
```

For NetCDF output you can test:

``` bash
ncview filename.nc
```

If the application window appears on the Mac, X11 forwarding is working.

## Linux

A Linux desktop normally already has the components needed to display
X11 applications, although this varies by distribution and desktop
environment.

Connect with:

``` bash
ssh -X -p 2022 student@localhost
```

Then test:

``` bash
xeyes
```

## Windows

Windows does not normally provide an X server by default. X11 forwarding
therefore requires a separate Windows X server and additional
configuration.

For the taught practicals, installing an X server is generally
unnecessary unless a practical specifically requires an interactive
Linux graphical application. Output stored in `~/work` can instead be
opened directly from the Windows `student_work` folder.

## Chromebook

X11 behaviour depends on the ChromeOS/Linux configuration and may vary
between devices. It is not required for the basic EnvModelling workflow.

Where possible, use plots and animations saved into `~/work` and open
them through the shared `student_work` directory.

## Troubleshooting

Check that you connected using:

``` bash
ssh -X -p 2022 student@localhost
```

Inside the SSH session:

``` bash
echo $DISPLAY
```

A non-empty value normally indicates that X11 forwarding has been
established.

Then try:

``` bash
xeyes
```

If X11 is not available, this does not prevent command-line model runs
or the creation of plots and animations as files.
